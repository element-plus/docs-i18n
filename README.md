# Element Plus Docs Translations

Machine-translated Element Plus documentation (`.md` source files), synced from Crowdin.

This repository is updated automatically by the [docs deploy workflow](https://github.com/element-plus/element-plus/blob/dev/.github/workflows/publish-docs-deploy.yml) on every release. Manual edits here will be overwritten on the next sync.

## Structure

- `zh-CN/` — Simplified Chinese docs
- `es-ES/` — Spanish docs

> Only markdown files are kept here. Built website pages (including all locales) are published to [element-plus/vercel-publish](https://github.com/element-plus/vercel-publish).
